# Windows 新手使用

下载 [Windows 新手包](https://github.com/uuoov/AutoSZUWeb/releases/tag/vpn-assistant-preview-1)。这是预览版，先在自己的电脑上试用。

你不需要安装 Python，不需要打开命令行，也不需要知道代理端口。解压整个压缩包，然后双击 `AutoSZUWeb-Connect.exe`（连接助手）。不要直接在压缩包里运行。

## 开始前准备什么

- 电脑已经连上深大校园网；
- 如果要使用 VPN，你需要已有 VPN 软件、可用的账号或订阅，并能在那个软件里手动连接成功。

连接助手不会提供 VPN 线路、购买订阅或替你注册账号。如果连 VPN 软件本身都没有，请先向服务提供方确认安装与连接方法。仅需要校园网自动登录时，可以只使用压缩包中的 `AutoSZUWeb.exe`。

## 照着三步做

1. **设置校园网**：在连接助手里点“设置 / 启动校园网”。首次启动会在桌面生成 `userdata.txt`：第一行填校园卡号，第二行填统一身份认证密码，保存后再次点这个按钮。认证提示出现后点“确定”。已经设置并运行过的用户可跳过。校园网程序会保存加密凭据，配置完成后删除输入文件，并启用自己的登录自启动。
2. **连接 VPN**：打开自己原来的 VPN 软件，选好线路，点击“连接”。先确认它能正常使用。
3. **检测并开始**：回到连接助手，点“自动检测连接”。找到可用连接后，点“开始监测”。有多个结果时，选择你正在使用的客户端。助手自动识别系统代理、已运行的常见客户端和少量常见本机地址，并实际测试能否通过该代理访问测试网址。端口由助手处理，不用手填。

看到“校园网检测通过，所选代理访问测试通过”即可保持运行。可以最小化窗口。

## 能自动做什么

| 你遇到的情况 | 当前新手包的行为 |
|---|---|
| 校园网掉线 | 独立运行的校园网程序尝试重新认证 |
| 已连接的代理正常 | 连接助手持续检测，显示结果 |
| 代理访问失败 | 提示到 VPN 软件重新连接或更换线路，并继续检测 |
| 需要自动启动 VPN、选择节点、连接单位 VPN | 当前新手入口没有这些配置；需要按[高级指南](https://github.com/uuoov/AutoSZUWeb/blob/main/docs/vpn-sync.md)接入客户端 |

**自动识别可用代理不等于能自动重连任意 VPN。** 测试通过也只代表指定网址可经所选代理访问，不保证每个网站都能打开，也不能保证流量使用了某条特定远端线路。

## 检测不到怎么办

先到 VPN 软件里确认已连接，再检测一次。Clash 类客户端可尝试打开“系统代理”，然后重新检测。

如果 VPN 已连接但仍找不到，可能是测试网址不可用，或客户端仅提供 SOCKS、TUN / 全隧道、单位专用内网连接。这些情况不能用这个新手入口直接判断；找不到不等于 VPN 一定断开。向帮你配置的人提供客户端名称，按[高级指南](https://github.com/uuoov/AutoSZUWeb/blob/main/docs/vpn-sync.md)设置合适的接入方法。

若校园网程序无法认证，可先在 VPN 软件手动断开，等校园网登录成功后再连接 VPN。代理入口不会自动修改 TUN、路由、订阅或系统代理开关。

## 停止和下次使用

- 点“停止监测”或关闭助手窗口，就会停止本窗口的代理监测；不会关闭 VPN 软件，也不会停止独立的校园网程序。
- 连接助手目前不会设置自己的登录自启动；下次需要重新打开、检测并开始监测。
- 校园网程序有自己的登录自启动，和连接助手分开。如需停用它，参见[主 README 的卸载说明](https://github.com/uuoov/AutoSZUWeb#卸载)。
- 助手的设置和日志保存在 `%APPDATA%\AutoSZUWebVPNSync`，不用修改它们，也不要把校园网密码或订阅地址发给别人。

## 给维护者：构建新手包

Windows 安装 Python 3.13 和 `PyInstaller==6.19.0` 后：

```powershell
python -m PyInstaller --noconfirm --onefile --windowed --noupx --name AutoSZUWeb-Connect --specpath build/vpn-assistant --workpath build/vpn-assistant/work --distpath dist/beginner scripts/vpn_setup.py
```

将同一次构建的原生 `AutoSZUWeb.exe`、`LICENSE` 和这份说明一并放入分发目录，压缩后分发。自动构建会上传 `AutoSZUWeb-Windows-Beginner` 产物。这个入口目前仅支持 Windows；其他平台继续使用高级脚本。
